# XTMEM 引擎（packages/memory/vendor/xtmem）的 Python 运行时依赖
#
# ▍这是什么
# 记忆适配器通过子进程调用 vendored 的 `xtmem.py`。Node 侧不需要装这些包，
# 但**Python 侧必须有**，否则引擎一启动就 ImportError。
#
# ▍怎么用
#   py -m pip install -r packages/memory/requirements.txt      # Windows
#   python3 -m pip install -r packages/memory/requirements.txt # macOS/Linux
#
# ▍为什么单独一个文件而不是写进 README
# `pip install -r` 要能直接跑；写在文档里靠人抄，一定会漏。
# 版本给下界不给死，避免和新 Python 版本相互卡死。
# ================================================================
