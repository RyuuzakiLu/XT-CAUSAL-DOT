# ASTRA · DOT 七状态动作素材 v2

状态顺序：待机 idle、思考 thinking、用户正在输入 user-typing、AI 正在输出 responding、AI 正在工作 working、主动提醒 reminder、完成 done。

- originals/：保留用户上传的原始透明高清状态图，未经重绘或缩放。
- sheets/：各状态 3×2 格 PNG 图集，1536×1024，每格 512×512，按从左到右、从上到下播放。
- frames/：42 张独立 RGBA 透明动作帧。
- previews/：深蓝背景 GIF，仅用作预览，正式素材请用 PNG。
- manifest.json：状态名称、帧路径、建议每帧时长和循环标记。

生成动作采用轻微呼吸、眨眼、头部和手势变化。完成状态建议播放一次后回 idle；其他循环状态由 DOT 业务事件切换。主动提醒需要用户确认后回 idle。用户输入状态是倾听姿态，角色不会敲键盘。未提供异常状态，不映射为其他状态。

画质说明：原始图保留原有分辨率；生成动画帧实际为 512×512，并非 1024×1024。建议悬浮角色显示高度 96–192 CSS px；高倍放大不等于新增细节。半透明抗锯齿轮廓需保留，禁止给精灵添加背景或滤镜模糊。渲染使用 image-rendering:auto，避免 pixelated。每帧保持相同容器和底部中心锚点，不要单独裁掉透明边距后再拉伸；这样更能避免跳位。生成的细节会有轻微逐帧变化，正式接入前请按目标尺寸检查。

制作方式：基于每张用户状态母版，使用内置图像生成制作六帧动作；脚本仅拆分图格并生成预览，没有重绘原图。完整每状态动作提示见 manifest.json 的 generationPrompt。
