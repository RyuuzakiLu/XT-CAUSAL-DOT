# XTCAUSAL DOT — ASTRA Q版精灵资源包 v1.0

七种状态：Idle、Typing、Thinking、Responding、Working、Reminder、Done。

每张独立 PNG 为 **1536×1536 RGBA**；以原始 1254×1254 图片为基础，只进行透明画布扩展与脚底基线对齐，不重新绘制角色。

`sprites.json` 包含每张图的偏移、锚点、图集坐标。`astra_chibi_atlas_4x2.png` 为 4列×2行的规则图集，最后一格为空。

注意：这些是 **状态差分**，并非逐帧动作动画。原始 AI 图片的边缘有少量彩色杂散像素和半透明边缘，尚未做破坏性清理；若需高品质成品，请先人工检查并精修。不同状态发型轮廓存在轻微差异，画布对齐不代表逐像素一致。

建议前端以独立 PNG 加载，切换状态时使用 100–200ms 淡入淡出，并叠加轻微呼吸/浮动效果。
